## MTerm چیه؟

MTerm یه ترمینال SSH جیبیه برای مدیریت سرورهای لینوکسی‌تون، مخصوصاً VPS‌هایی که روشون پنل‌هایی مثل 3X-UI یا Marzban نصبه. سرورتون رو یه بار اضافه می‌کنید و از اون به بعد با یه لمس وصل می‌شید؛ بدون هیچ سرور واسطه‌ای و بدون ثبت‌نام. اتصال مستقیم از گوشی یا کامپیوتر شما به سرور خودتونه.

## امکانات

- **ترمینال کامل SSH** با نوار کلیدهای اضافه (Ctrl، Esc، Tab، کلیدهای جهت) که قابل شخصی‌سازیه
- **ورود با رمز یا کلید SSH**: کلید خصوصی رو می‌شه مستقیم از کلیپ‌بورد وارد کرد
- **اتصال سریع ⚡**: فقط آدرس و رمز رو بزنید و وصل شید، بعد اگه خواستید سرور رو ذخیره کنید
- **ذخیرهٔ سرورها و رمزها**: آی‌پی و رمز یه بار ذخیره می‌شه و دفعهٔ بعد خودکار وصل می‌شید؛ اگه رمز سرور عوض شده باشه، رمز جدید جایگزین می‌شه
- **دستورات آماده**: کتابخونه‌ای از دستورهای پرکاربرد برای مدیریت سرور، 3X-UI، Marzban، کاریز و BackPack؛ دستورهای حساس مثل نصب یا ریبوت قبل از اجرا تأیید می‌گیرن
- **دستورات شخصی**: دستورهای خودتون رو ذخیره کنید و با یه لمس اجرا کنید
- **امنیت کلید سرور**: اثر انگشت کلید هر سرور بررسی و به خاطر سپرده می‌شه تا اتصال جعلی شناسایی بشه
- **قفل برنامه**: با PIN یا اثر انگشت، با قفل خودکار بعد از مدت دلخواه
- **۹ زبان**: فارسی، انگلیسی، عربی، ترکی، روسی، آلمانی، فرانسوی، اسپانیایی و چینی
- **تم روشن، تیره یا هماهنگ با سیستم**
- **به‌روزرسانی بدون حذف**: نسخه‌های جدید روی قبلی نصب می‌شن و سرورها و رمزها سر جاشون می‌مونن

## English

MTerm is a pocket SSH terminal for managing your own Linux servers, especially VPSes running panels such as 3X-UI or Marzban. Add a server once and connect with one tap. No account, no middle server: the app connects straight from your device to your server.

**Features**

- Full SSH terminal with a customizable extra key bar (Ctrl, Esc, Tab, arrows)
- Password or SSH key login, with key paste from the clipboard
- ⚡ Quick Connect: type an address and password, connect, and save the server afterwards if you like
- Saved servers and passwords, updated automatically when a server's password changes
- Ready-made command library for server admin, 3X-UI, Marzban, Kariz and BackPack, with confirmation before installers or reboots
- Your own saved commands, run with one tap
- Host key verification to spot spoofed servers
- App lock with PIN or fingerprint, auto-lock after a set time
- 9 languages: Persian, English, Arabic, Turkish, Russian, German, French, Spanish, Chinese
- Light, dark or system theme
- In-place updates that keep your servers and passwords

**Install:** Android, download the `.apk` and allow installs from unknown sources. Windows (x64), unzip and run `MTerm.exe`.
